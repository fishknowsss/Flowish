# Solid Glass 材质适配 · 2026-10-19

根据最终要求，撤回此前的版式重构，以 `d5594db` 为布局基线，再追加独立材质层。保留 Git 历史，通过新提交记录恢复与适配结果。

## 实现边界

- `App.tsx`、全部组件、测试、`tokens.css`、`base.css` 和 `workbench.css` 恢复至基线，内容逐字一致。
- `main.tsx` 只新增末尾样式导入；`solid-glass.css` 只包含颜色、背景、圆角、边框颜色、阴影、模糊、光标和选区样式。
- 未修改 DOM 顺序、布局、字体、字号、行高、边框宽度、尺寸、间距、滚动规则或断点。原始背景网格以 `background-image: none` 覆盖，实际页面无可见渐变。
- 浅色为中性灰上的烟白玻璃，深色为炭灰玻璃；高光集中在边缘。面板、卡片、弹层依次增加厚度。仅顶栏与浮层使用背景模糊。
- 保留重点、积压、节律、日期的语义色。表单与短句栏保持原来的透明容器，避免重复玻璃框。
- 保留 `4cded88` 的 CSP 字体修复：`font-src 'self' data:`。生产预览确认基线会阻止三个内嵌字体加载，此修复只开放字体的数据 URL。
