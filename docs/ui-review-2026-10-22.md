## 发现与修复

| 问题与证据 | 原因 | 修复 |
| --- | --- | --- |
| 820px / 390px 下，日历与重要日期分别重叠 150px / 90px | 时间板仍固定第一行 360px，子面板最小高度却为 520px / 460px | 窄屏采用内容高度，月历与日期详情分别分配空间 |
| 固定节律面板 200px，列表实际仅约 83px；周进度与操作超出 | 固定低高度、单排卡片、可压缩行 | 增加节律区域，卡片自动换列，行高取内容高度，列表独立滚动 |
| 多条长任务时标题、日期和按钮互相覆盖 | Grid 的默认隐式行可压缩至 52px，而换行后的实际内容远高于此值 | 任务与节律使用 `grid-auto-rows: max-content`，滚动容器容纳长列表 |
| 1440×900 只有两条日期却各自拉伸至约 309px | 列表默认行伸展，面板又占满剩余高度 | 日期区域限额分配，卡片按内容高度排布，留出编辑操作区域 |
| 1280px 就切换至大幅滚动的布局 | 1320px 断点与实际栏宽需求不符 | 三栏支持到 1200px；更窄或低于 720px 高度时使用流式布局 |
| 手机总览、短句和工具栏过高，日期按钮换行 | 单列总览、短句单列网格，工具按钮缺少宽度保障 | 总览保留双列摘要；短句横排；计时和工具分行；日历控制组完整换行 |
| 320px 菜单向左越界约 14px | 弹层锚定在窄小的设置按钮上 | 手机菜单锚定整条工具栏，并限制高度、允许内部滚动 |
| 大面积近白表面与重复控件阴影，栏目难区分 | 所有大面板使用近白背景和相同阴影 | 暖灰绿底，今日重点用浅陶土灰、积压用青灰、节律用鼠尾草绿、日期用石色；减弱控件阴影 |
| 浅色部分小字与色标对比不足，完成项整体透明后更淡 | 灰字与底色过近；对整块内容降低透明度 | 加深辅助文字和陶土色；完成、过期及非本月状态通过文字与底色区分，取消整体淡化 |
