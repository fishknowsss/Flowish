## 卡片与分页

- 重要日期最多 4 列×2 行，节律最多 3 列×2 行。分页同时参考区域宽高和内容高度；短屏减少行列数，优先完整呈现卡片。长标题保留换行，极长内容可在卡片内滚动。
- 页内卡片紧凑排列，避免均分行高造成过大空隙。所有页面保持挂载，搜索定位直接对齐目标整页，并聚焦结果。
- 箭头、左右方向键、Home / End、触屏横向滑动均可翻页；保留 CSS Scroll Snap 原生吸附，不再移动整块 viewport 模拟边界回弹。
- 日期编辑占用当前分页的完整宽度，其他页保持原位；保存、取消后返回原卡片。编辑期间不重新划分页，避免编辑器失焦。
- 节律只显示七个星期状态元素；具体星期、日期和完成状态保留在 `aria-label` 与提示中。
- 删除全部拖拽按钮图标及展开排序面板。任务、节律仍可整卡拖动；聚焦卡片后通过 `Alt+ArrowUp` / `Alt+ArrowDown` 排序，并保留排序播报。
- 系统和应用内减少动态效果均关闭缩放与平滑翻页；减少透明度关闭弹层模糊。
