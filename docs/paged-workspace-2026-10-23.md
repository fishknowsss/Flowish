# 分页工作台与交互 · 2026-10-23

桌面布局调整为左侧今日重点与固定节律、中间日历与重要日期、右侧总览与积压事项。今日重点区域较小，积压区域更大；DOM 与视觉阅读顺序一致。窄屏按栏目流式排列，内容过长时允许页面增高，优先完整呈现卡片。

## 配色与材质

以 `dc4afd4` 的语义色为基础：仅将大面积中性表面改为米白、淡米黄；今日重点使用较明确的低饱和陶土橙，节律保留灰绿，积压保留灰青蓝，降低两者的明度和饱和度。深色主题延续原有配色。全站无渐变，PWA 启动底色同步。

## 卡片与翻页

- 共享 `CardPager`，重要日期最多 4 列×2 行，固定节律最多 3 列×2 行。根据容器实际宽度减列，每页仍最多两行，不把列数绑定到整页宽度。
- 箭头按钮、左右方向键、Home / End、原生触屏横向滑动均可翻页。使用 CSS Scroll Snap 整页吸附，保留浏览器惯性；边界横向滚轮带轻微弹簧回弹。
- 所有页面保持挂载，站内搜索和键盘焦点可以直接定位后续页。翻页落稳后卡片完整显示；内容不做截行。页面高度随最长卡片增长，避免纵向裁切。
- 日期卡片纵向排布，不再横向占半个区域；编辑时可跨两列，容纳日期输入与保存按钮。
- 节律排序、编辑、删除移至卡片右上角。星期文字改成七个状态元素，保留各日的 `aria-label` 和鼠标提示。

## 交互规则

- 鼠标环境下，任务、节律、日期、短句的次要操作在悬停或键盘聚焦时显示；编辑与排序状态持续显示。
- 触屏保留可见操作，不依赖 hover；触屏卡片操作最小目标为 24px。
- 统一按钮按下、悬停、危险操作、选中和禁用状态。任务操作放在元信息行，减少空白操作行；输入控件保留清晰焦点环。
- 弹层使用短距离进入，按钮按下反馈即时。系统及应用内减少动态效果均关闭弹性和缩放；减少透明度关闭模糊，提高对比度增强边框。
- 回弹仅在横向边界输入时启动，使用当前位移和速度，可连续输入；停止后取消动画循环，卸载清理事件与帧。

## 验证

- `npm run check` 通过：ESLint、20 个测试文件共 96 项测试、覆盖率门槛、TypeScript 和生产构建。新增分页跨页保留、数据删除后页码收敛、键盘减少动态效果及高度变化不打断翻页的回归测试。
- Chromium 检查 1440×900、1512×753、1280×800、1024×768、820×900、390×844、320×740；用 14 条节律、19 个日期及长标题检查分页。落稳后卡片裁切为 0，栏目重叠为 0，页面横向溢出为 0，可见渐变为 0。
- 搜索能定位并聚焦最后一页的节律；日期编辑完整显示，未出现字段溢出。鼠标操作栏透明度由 0 变 1，键盘聚焦也变 1。
- 生产预览：应用内减少动态效果时，按钮按下缩放为 1；横向边界位移约 3.2px，随后归零；独立触屏浏览器中所有操作可见，节律可点击编辑，模拟真实触屏滑动后日期吸附至第二页。控制台错误为 0。
- 两种主题各抽查 219 处直接文字，对比度检查无不足项。该检查覆盖当前样本，未作完整屏幕阅读器或真实 iPhone Safari 验收。

分页诊断使用卡片实际矩形作为通过信号。尺寸监听只响应宽度变化，避免文字高度变化打断正在进行的翻页；外层使用 `overflow: clip`，避免焦点滚动引起嵌套滚动偏移。检查等待吸附落稳，不把滚动过程中的半页状态当成最终状态。
